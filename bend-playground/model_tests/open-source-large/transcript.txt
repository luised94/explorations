Fork tree shape
Each renderer is a balanced binary fork tree of depth d (Mandelbrot d = 5  32 leaves; Sierpinski d = 4  16 leaves). At each internal node a parallel let splits the row range in half; each leaf renders one row as a flat tail-recursive loop over columns. The two images are themselves computed in a top-level parallel let, so the root forks into two independent sub-trees. This matches the shader guide's "one fork tree that ends in flat loops" pattern.
Laws chosen and why
Every law targets a function whose body reduces entirely through structurally-defined Base operations (U32 bitwise AND via Word.and, U32.is_eq via Word.cmp, Bool/Char matches). F32 operations are opaque law declarations, so no law can mention the Mandelbrot iteration's numeric behaviour - only the character-selection Bool branch is provable. Ground-term instances were chosen over universal laws (e.g., "for all row, col 0 is filled") because the latter would require a 32-level Word induction with Equal.sym rewrites, adding proof fragility without additional language coverage.
