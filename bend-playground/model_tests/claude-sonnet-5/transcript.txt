Strategy
Grid pipeline, shared shape, not shared code. Both images reduce to: "for each (row, column) in a grid, compute one character." I want that computation to happen through an actual fork tree, not a single sequential loop, so I'll build it the way bend guide shaders builds the rasterizer: fork on a Nat level parameter that bisects the row range in half at each step (mirroring pow2 and Frame.node's "peel the first, decreasing, parameter" pattern), down to a leaf that renders one row with a flat tail-recursive loop over columns. That gives a balanced binary fork tree of depth level (e.g. level = 5n  32 leaves/rows), with each leaf doing the guide's recommended "flat loop, no fork" work. Row width is not forked (per the shader guide's own warning that forking per-cell or per-pixel "drowns in scheduling"; forking rows and looping columns is the same tradeoff the reference rasterizer makes at its tile boundary).

Rejected alternative, and why: I considered one generic Grid.render_row(~cell: Nat -> Nat -> Char, ...) template parameter shared by both images. I'm rejecting it: a law that wants to say something about that function has to either fix ~cell to a concrete top-level def (fine) or quantify over an arbitrary function value passed into a ~ (template) slot - but the guide is explicit that a ~ argument "must be closed: it may mention top-level defs, but no local variable of the caller." A universally-quantified law variable used as a ~ argument inside its own proof is exactly a local variable in a template slot, i.e. not closed. Rather than gamble on whether the checker special-cases this, I'll write two small, independent, non-templated pairs of functions (Sierpinski.render_row/Sierpinski.render_rows and Mandel.render_row/Mandel.render_rows), each calling its own .cell def directly. This is duplication the flat-style rule would normally forbid, but it's forced by a real rule of the language (the closedness restriction on ~), so I'll say so in a comment at the site, per your instruction.

Per-cell functions:

Sierpinski: cell(row, col) = '*' if U32.and(row_as_u32, col_as_u32) is zero, else ' '.
