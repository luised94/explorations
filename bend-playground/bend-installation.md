# install bend

```bash
curl -fsSL https://bend-lang.com/install.sh | sh
downloading https://github.com/bendlang/bend/releases/download/v2.0.16/bend-2.0.16-linux-x64.tar.gz

  Bend Û  2.0.16

  Bend is installed at ~/.bend. Run bend guide to get started.

  Add it to your PATH: export PATH="$HOME/.bend/bin:$PATH"
  Once a day, bend asks bend-lang.com for the latest version, sending
  only its version, OS and CPU type. BEND_NO_TELEMETRY=1 turns that off.

  Congratulations! You're now a code bender.
export PATH="$HOME/.bend/bin:$PATH"
bend --help # confirm
```
