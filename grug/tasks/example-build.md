# Merge overlapping intervals

Write `merge_intervals(intervals)` in Python 3.12, standard library only.
Input: a list of (start, end) integer pairs with start <= end, in any order.
Output: a sorted list of pairs where overlapping or touching pairs are merged.
Example: [(1, 3), (2, 5), (7, 8), (5, 6)] -> [(1, 6), (7, 8)].

Done means: the function, a test file covering empty input, one pair, nested
pairs, touching pairs and unsorted input, and the output of running the tests.
