# Domain: writing (docs, comments, writeups)

- Write to prevent rediscovery, not to build a monument.
- Lead with the result or decision. Then why, limits, and when to revisit.
- Keep apart what a source says, what we infer, and what we observed.
- Docs: purpose, boundary, assumptions, how to recover when it breaks. Put
  detail next to the code it describes.
- Decision note: choice, reason, confidence, revisit trigger. A decision with
  no trigger hardens into dogma.
- One concrete example beats a general paragraph.
- Compression picks the one decisive consequence. It is a hook, not proof.
  Test: can a teammate turn the sentence into a decision and a condition for
  changing it? If not, it is a slogan.
