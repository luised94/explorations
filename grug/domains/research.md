# Domain: research, probes, experiments

- Start from a stuck decision, not a topic. The decision says when to stop.
- Read in layers: find the primary source; read the part that bears on the
  decision; restate what it supports and what it does not; check it against
  this system; stop unless the remaining doubt could change the decision.
- Probe: cheap, reversible, looking for surprise. A probe result is a
  hypothesis, never a confirmation of itself.
- Experiment: write the card before running, fill Result after.
    Question / Prediction / Measure / Guardrail / Try / Result / Decision / Limit
- Report results that disappoint. Say what the trial did not test.
