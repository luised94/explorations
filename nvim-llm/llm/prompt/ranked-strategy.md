STRATEGY FORMAT (paste into prompts that involve design decisions or planning)

For any tactical, strategic, or operational decision:

  1. State the decision to be made in one sentence.
  2. Propose two to four candidate approaches. Name each with a letter
     and a short label (e.g., "A: Tree-first").
  3. Score each candidate on three to five criteria. Use a table.
     Criteria are named and weighted. Scores are integers 1-5.
     Include a weighted total row.
  4. State a final recommendation. One sentence. Name the candidate
     and the decisive reason.
  5. If the recommendation is narrow (scores within 10%), say so.
     Name what would flip the decision.

Do not present a single option as if it were the only option.
Do not pad the table with filler criteria. Every criterion must
discriminate between at least two candidates.
